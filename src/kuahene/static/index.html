Select Appliance Network Interface

Choose which network interface agents should connect to. This address will be embedded in all agent install scripts.

Not seeing your IP? Run this on the host to detect all interfaces:

PowerShell (Windows):

powershell -c "$b='http://localhost:8000/api/agents/report-interfaces';$n=Get-NetIPAddress -AddressFamily IPv4|?{$_.IPAddress-notmatch'^(127\.|169\.254)'}|%{@{ip=$_.IPAddress;name=$_.InterfaceAlias}};irm $b -Method POST -ContentType 'application/json' -Body (@{interfaces=@($n)}|ConvertTo-Json -Depth 3)"

Bash (Linux/macOS):

ip -4 -o addr show | awk '{gsub(/\/.*/, "", $4); if ($4 !~ /^127\./) print "{\"ip\":\""$4"\",\"name\":\""$2"\"}"}' | jq -s '{interfaces:.}' | curl -sX POST http://localhost:8000/api/agents/report-interfaces -H 'Content-Type: application/json' -d @-
